# 34 — Man page, completions, help golden tests

## Title
Man page, shell completions, and help golden tests

## Summary
Generate a man page (`clap_mangen`) and shell completions (`clap_complete`) from the CLI
definition, and add golden/snapshot tests for `--help`, the man page, and completions so
docs never drift from the actual flags (DESIGN §4, §15).

## Context
Accurate, generated docs are part of the OSS baseline. Golden tests keep DESIGN §4.2's flag
set and the shipped docs in lockstep.

## Scope
- In: `dryrun completions <shell>` output wiring, a build/generation path for the man page,
  golden tests for help/man/completions, install docs.
- Out: README prose (37); release packaging of these artifacts (36).

## Detailed Requirements
1. `dryrun completions <bash|zsh|fish|powershell>` prints a completion script generated by
   `clap_complete` from the 03 command definition.
2. Man page: generate `dryrun.1` from the clap command via `clap_mangen`, either in a
   `build.rs`/`xtask` or a `completions`-style subcommand; commit or produce-in-CI for
   release packaging (36 installs it).
3. Golden tests (`insta` or committed fixtures):
   - `--help` output snapshot (normalized for version).
   - man page snapshot (normalized).
   - one completion (e.g. bash) snapshot.
   Each fails if a flag is added/renamed without updating docs — the point of the test.
4. Ensure long-help text authored in 03 is present for the security-relevant flags
   (`--allow-network`, `--writable`, `--writable-force`, `--engine`, `--no-execute`).
5. Document how to install the man page/completions in 37/README.

## Acceptance Criteria
- `dryrun completions bash|zsh|fish` produce valid scripts.
- A man page is generated and renders (e.g. `man ./dryrun.1` or `mandoc -T lint`).
- Golden tests catch a flag change (verified by temporarily adding a flag → snapshot test
  fails → revert).

## Validation
- `cargo test --test cli_help_golden` (+ man/completions snapshots). Wired into CI (33).

## Dependencies
03.

## Non-goals
No README (37); no release upload (36).
